# 代码审查（Code Review）

## 审查维度

1. **正确性**：逻辑是否成立、边界条件、错误处理、并发/异步状态。
2. **安全性**：输入校验、注入、权限、敏感信息泄露。
3. **可维护性**：命名、单一职责、重复代码、测试覆盖、文档。
4. **性能**：明显低效的算法、N+1 查询、资源未释放。
5. **生命周期**：资源清理（disposer/close）、取消信号、热更新安全。

## 输出模板

```
## 结论
✅ 通过 / ⚠️ 需修改（N 个阻塞项）/ ❌ 驳回

## 阻塞项（必须改）
- [P0] 位置：问题 → 建议

## 建议项
- [P1/P2] 位置：问题 → 建议

## 好评
- 做得好的地方
```
