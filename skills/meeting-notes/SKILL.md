# 会议纪要（Meeting Notes）

## 提取维度

1. **主题与参会人**：一句话概括会议主题。
2. **决策**：会上拍板的事项（"决定……"），记录决策理由。
3. **待办（Action Items）**：谁、做什么、何时完成。
4. **结论/共识**：达成一致的结论。
5. **分歧与风险**：未解决的分歧、被搁置的事项、潜在风险。

## 输出模板

```
# 会议纪要 · <主题> · <日期>

**一句话结论：** ...

## 决策
- 决定：...（理由：...）

## 待办
- [ ] <负责人>：...（截止：...）

## 共识
- ...

## 分歧 / 风险
- ...
```
