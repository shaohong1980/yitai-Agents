# 报告写作（Report Writing）

## 结构

1. **一句话结论**：最想让人记住的核心结论放最前（"电梯陈述"）。
2. **关键指标**：用数字/表格呈现核心数据，标注口径与来源。
3. **正文展开**：按重要性排序，每节一个主题，先结论后论据。
4. **行动项**：明确下一步、负责人、时间。
5. **附录**：原始数据、详细日志、参考来源。

## 原则

- 用主动语态、短句；避免模糊词（"大概""可能"）。
- 每个数字都要有单位、时间点、来源。
- 结论与论据分开，让读者能快速跳读。
- 中文报告保持"结论先行"结构。

## 模板

```
# 标题（含时间范围）

**一句话结论：** ...

## 关键指标
| 指标 | 数值 | 环比 |

## 分项
### 1. ...
结论 → 依据 → 影响

## 行动项
- [ ] ...（负责人 / 截止）
```
