# 网络调研（Web Research）

## 工作流

1. **明确检索意图**：确定要回答的问题、限定范围（时间/地区/语言）、期望的输出格式。
2. **多路检索**：用多个关键词变体搜索；覆盖官网、官方文档、社区、竞品页面。
3. **抓取关键页面**：优先抓取一手来源（官方文档/原论文/权威媒体），二手来源标注"转引"。
4. **信息筛选**：去重、按可信度排序、保留时间戳（信息可能已过期）。
5. **输出带来源的摘要**：每条结论附上 URL 与获取时间；不同来源有分歧时并列列出。

## 摘要模板

```
## 调研结论
1. ... （来源: URL）
2. ...

## 分歧点
- 来源A 认为 ...，来源B 认为 ...

## 建议下一步
- 若需更深入，可抓取 ...
```
